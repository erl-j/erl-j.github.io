This measures style, not authorship. Humans write slop and models can avoid it. Do not use it to make decisions about people (grading, hiring, misconduct).

← Back to the detector

The rule set

91 features: the 87 in the scored model and 4 artefact-variant features that are defined but not scored. Each feature is code written by hand (regexes, word lists, counts); a logistic regression learned on the v2 training split weights them. A positive weight means a higher value pushes the score toward AI style. Features are sorted by |weight| within each family. Model slop_lr, export sha256 c32b8dc271b5, built from commit ac9dd98.

The direction observed on our training data often disagrees with the folk tell: those rows say "reversed" in their rationale.
